# Support

## Questions and usage help

Before asking for help:

1. Read the [README](README.md) and the guides in [`docs/`](docs/).
2. Search existing [issues](https://github.com/allisonwang-db/pyspark-udtf/issues).
3. Confirm that you are using Python 3.10 or later and a supported PySpark version.

If the problem remains, open a GitHub issue using the appropriate template. Include a minimal reproducible example, package versions, the complete error message, and the expected result. Remove credentials and sensitive data from all examples and logs.

## Bugs and feature requests

- Use the bug report form for reproducible defects.
- Use the feature request form for new UDTFs and enhancements.
- Follow the [security policy](SECURITY.md) instead of opening a public issue for suspected vulnerabilities.

Maintainers and contributors provide support on a best-effort basis; response times are not guaranteed.
